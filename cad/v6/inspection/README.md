# V6 — six static inspection views

Actual FreeCAD renders of the saved V6 model, at 2048 × 1536 pixels.
All six use orthographic projection, one common scale, closed RNA, 11 bead
steps and a resting upper input. The model is opened read-only for rendering;
its saved geometry and motion are unchanged.
